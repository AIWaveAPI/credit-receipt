# Contributing

Start with a reproducible accounting failure, a synthetic fixture, and an official source for any proposed rate rule. A native platform importer requires a user-owned export format that can be inspected without credentials or private endpoints.

Run `python -m unittest discover -s tests -v` before a pull request. Keep provider-specific rules dated and cite the exact official page. Do not add scraped account data, personal identifiers, task content, screenshots of private billing, credentials, or unverified prices to the repository.

When a rule or raw usage field is unavailable, return `insufficient_data`. Do not turn absence into zero, silently estimate token counts, or label a platform dishonest based on an arithmetic discrepancy alone.
